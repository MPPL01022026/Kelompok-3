## 📌 Tentang Project

**SIKAP (Sistem Kasir PSC Coffee)** merupakan sistem kasir berbasis web yang dikembangkan untuk membantu proses transaksi dan pencatatan penjualan di **PSC Coffee – Universitas Samudra**.

Sistem ini dirancang untuk mengurangi ketergantungan terhadap proses pencatatan manual menggunakan Excel serta membantu meningkatkan efisiensi proses operasional kasir.

Selain sistem kasir, project ini juga mencakup **Digital Twin PSC Coffee** untuk memberikan representasi digital terhadap kondisi operasional.

---

## 🎯 Tujuan Project

Project ini bertujuan untuk:

* Meningkatkan efisiensi proses transaksi.
* Membantu pencatatan transaksi secara digital.
* Mengurangi kesalahan dalam pencatatan penjualan.
* Menyediakan laporan transaksi.
* Menyediakan representasi digital operasional melalui Digital Twin.

---

## ✨ Fitur Utama

### 🔐 Login & Authentication

Sistem login untuk mengatur akses pengguna ke dalam sistem.

### 🛒 Pengelolaan Order

Mendukung proses pengelolaan pesanan pelanggan.

### 💰 Transaksi Kasir

Membantu proses transaksi penjualan secara digital.

### 📊 Laporan Transaksi

Menyediakan informasi dan laporan dari transaksi yang telah dilakukan.

### 🏪 Digital Twin

Menyediakan representasi digital dari kondisi operasional PSC Coffee.
